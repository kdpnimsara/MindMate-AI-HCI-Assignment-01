# Team Responsibilities

| Member    | Main Responsibility                          |
| --------- | -------------------------------------------- |
| Member 01 | Project coordination and progress monitoring |
| Member 02 | User interviews                              |
| Member 03 | Survey creation and distribution             |
| Member 04 | User research analysis                       |
| Member 05 | Personas and empathy map                     |
| Member 06 | User journey and user flow                   |
| Member 07 | Sketches and low-fidelity wireframes         |
| Member 08 | High-fidelity Figma UI design                |
| Member 09 | Brand guidelines and visual identity         |
| Member 10 | Documentation, UX portfolio and presentation |

## Shared Responsibilities

All members should participate in:

* Project reviews and discussions
* Prototype development and feedback
* Usability testing
* Final report preparation
* Final presentation and live demonstration
* LinkedIn professional showcase

## Contribution Tracking

Each member's actual contributions should be recorded throughout the project to ensure transparency and fair participation.
