# Project Objectives

## Main Objective

To design an interactive AI-based study assistant that supports personalized and user-friendly learning experiences for university students.

## Specific Objectives

1. To understand the study-related challenges and difficulties experienced by university students.
2. To identify user needs, expectations, and pain points through genuine user research.
3. To identify suitable features based on research findings.
4. To design a simple, accessible, and user-friendly mobile application interface.
5. To provide personalized study recommendations based on voluntarily provided mood feedback, learning preferences, and study progress.
6. To create clear user flows and low-fidelity wireframes.
7. To develop a consistent brand identity and high-fidelity user interface designs.
8. To develop an interactive Figma prototype.
9. To evaluate the usability of the prototype through user testing.
10. To improve the design based on feedback received during usability testing.
