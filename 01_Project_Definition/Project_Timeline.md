# 14-Day Project Timeline

| Day | Activity                                    | Expected Output                                                        |
| --- | ------------------------------------------- | ---------------------------------------------------------------------- |
| 01  | Project definition and research preparation | Project overview, problem statement, objectives and research questions |
| 02  | Survey distribution and user interviews     | Genuine survey responses and interview notes                           |
| 03  | User research analysis                      | Research findings, user needs and pain points                          |
| 04  | Personas and empathy map                    | User personas and empathy map                                          |
| 05  | User journey and How Might We questions     | User journey map and HMW questions                                     |
| 06  | Feature prioritization and user flow        | Prioritized feature list and user flow diagram                         |
| 07  | Sketches and low-fidelity wireframes        | Initial sketches and wireframes                                        |
| 08  | Brand guidelines and visual direction       | Logo concept, colors, typography and brand guidelines                  |
| 09  | Main UI design                              | Main application screens                                               |
| 10  | Remaining UI screens                        | Completed high-fidelity UI screens                                     |
| 11  | Interactive Figma prototype                 | Clickable prototype demonstrating the main user journey                |
| 12  | Usability testing and improvements          | Genuine user feedback and refined prototype                            |
| 13  | Final report and UX portfolio               | Completed report and portfolio                                         |
| 14  | Presentation and final review               | Presentation slides and final demonstration                            |

## Timeline Management

* All members should complete their assigned tasks according to the timeline.
* Related activities may be completed in parallel where possible.
* The project coordinator should monitor progress.
* Regular group reviews should be conducted.
* Any changes to the timeline should be recorded.

**Note:** This is a proposed timeline. Adjust it according to the actual assignment deadline and group progress.
