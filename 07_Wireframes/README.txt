MINDMATE AI – TASK 07 LOW-FIDELITY WIREFRAMES

This package contains 13 grayscale mobile wireframes derived from the supplied Feature Prioritisation & User Flow document.

Files:
- SVG_Wireframes/: editable vector screens. Import an SVG into Figma using File > Place image or drag-and-drop.
- PNG_Previews/: visual references.
- Wireframes_Overview.png: all 13 screens in one overview.
- MindMate_AI_Task07_Wireframe_Documentation.docx: accompanying design documentation.

Design constraints followed:
- Suggested schedules remain editable and are not final until confirmed.
- Mood input is optional and can be skipped.
- AI help and quizzes preserve the current study-task context.
- Only learner-confirmed task status changes are applied.
- Reminders are user-controlled.
- Grayscale boxes and placeholder text are used because this is low-fidelity, not final visual design.

Note about hand-drawn sketches:
These are digital low-fidelity wireframe references. If the lecturer explicitly requires physical hand-drawn evidence, redraw a few key layouts (Welcome, Home, Add Task, Review Plan, Task Workspace) on paper and photograph them; do not label these digital SVGs as hand-drawn.
