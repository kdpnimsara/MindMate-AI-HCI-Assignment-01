# MindMate AI — Task 08: Brand Guidelines

This folder is the Task 08 starting package for the MindMate AI HCI project.

## Contents
- `01_Documentation/`: Brand Guidelines and UI Design System (DOCX)
- `02_Brand_Assets/`: SVG primary logo lockup and app icon concept
- `03_Design_Tokens/`: CSS variables and JSON colour tokens

## Design direction
- Soft & Friendly
- Light mode default + optional dark mode
- Connected M symbol + MindMate AI wordmark
- Tagline: **Learn Smarter. Grow Together.**
- Plus Jakarta Sans headings + Inter body
- Rounded outline icons
- Lavender + Mint palette

## Important
The logo SVGs are first-pass vector concepts, not a final trademark-ready identity. Review at actual screen sizes before publication. Test implemented text/background combinations against WCAG 2.2 AA; pastel accent colours should not be used as small-text foreground colours.
